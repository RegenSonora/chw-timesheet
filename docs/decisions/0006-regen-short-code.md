# 0006 — Short code for Regen General Operating

- **Status:** Accepted by Chris, October 31, 2026
- **Spec:** SPEC §3, §5, §6, §7

## Decision

Each funding source has a short code, kept in its source file. TISUPP's is `TISUPP`. Regen General Operating's is `REGEN-GO`. The code is shown on the source chip and the Generate button ("Generate REGEN-GO invoice") and is the `<SOURCE>` part of file names (`REGEN-GO_CC-2026-005_entries.csv`). The full name is printed on the invoice.

## Why

The spec named file names and the chip by source but gave no short form for Regen General Operating; the full name is too long for the chip and file names.
