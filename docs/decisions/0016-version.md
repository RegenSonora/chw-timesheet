# 0016 — Version shown in Settings

- **Status:** Accepted by Chris, November 1, 2026
- **Spec:** SPEC §4, §9; BUILD_PLAN M5, M6

## Decision

The bottom of Settings shows the app version, for example **Version 0.9.0 (a1b2c3d)**: the release number and the first 7 characters of the commit it was built from.

The pilot release (M6) is **0.9.0**. Version 1.0.0 follows once the pilot confirms the app's totals match the spreadsheet.

## Why

The release checklist needs a way to see that an update arrived, and support needs to know which version a CHW has.
