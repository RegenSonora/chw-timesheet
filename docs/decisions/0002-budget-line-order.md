# 0002 — Budget line order

- **Status:** Accepted by Chris, October 31, 2026
- **Spec:** SPEC §6, §7

## Decision

Invoice lines (PDF page 1, invoice preview, QR) and the "Subtotal by budget line" block on each timesheet page list budget lines in the order of the funding source file's budget line list. Lines with no hours are left out.

## Why

The spec did not say. A fixed order lets the office find each line in the same place on every invoice. The wireframe sample lists lines in a different order; it was drawn before this was decided and does not set the rule.
